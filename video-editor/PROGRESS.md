## Dead ends
- Blocked from Claude's session: jsDelivr, unpkg and chromestatus.com (November 2, 2026; Mediabunny came from registry.npmjs.org); the platforms' rule pages and the Korean-look sources, read through search results only; developers.cloudflare.com, huggingface.co, openai.com and developers.openai.com: read Cloudflare's docs from their source on GitHub (`CLOUD-NOTES.md`). Also danielyoonwrites.github.io and any workers.dev address, including the captions server's (the proxy answers 403, November 4, 2026): a green publish run and Cloudflare's own check on GitHub are what Claude can see; Dan's phone is the first live look.
- 30-second sound pieces: too close to the free plan's 10 ms of the server's own work (measured November 4, 2026); pieces of up to 15 seconds instead. Sending the sound as a stream (a `body` with a `contentType`): in the model's file, but described nowhere else in Cloudflare's docs; base64 instead. Build watch paths narrower than `*`: still unclear in Cloudflare's docs (November 4, 2026).
- Claude's API can't take sound ("All current models support text and image input, text output," Anthropic's models page, read November 3, 2026), so the captions use Cloudflare's Whisper. Chrome's built-in speech recognition only listens to the microphone, not to a file.
- Line breaks made "as narrow as possible" (like CSS's balanced text) still left "I" at the end of a line; `textLines()` picks the most even breaks and keeps a one-letter word off a line's end when it can.
- scikit-image's test photos moved inside that project (their old paths answer 404), so the looks are judged on a made-up scene (`tests/make-scene.py`).
- An OffscreenCanvas ignores SVG filters (`url(#...)`); a normal canvas works, even one that isn't on the page.
- Loading Mediabunny as a module (`import`): its AAC add-on imports "mediabunny" by name, which needs an import map, an inline script the page's safety rule blocks. The plain script builds (a global `Mediabunny`) work instead.
- Mediabunny's one-step `Conversion` can trim but has no speed setting (its type notes, version 1.65.0), so the app makes each video frame by frame.
- A Web Audio high-pass filter with Q 0.707 made a 3.4 dB bump at 100 Hz: for that filter type Q is in decibels; −3.01 is the smooth shape.
- Timing the new video's sound by a sudden tone read 14 thousandths of a second late: AAC smears a sudden start. Lining up a hiss (`soundLag()` in `tests/test-videos.mjs`) shows it's in line to the sample.
- In the checks, `innerText` of words inside a closed fold-out or a hidden tab is empty; open the tab first, or read them with `textContent`.

## How to run and check it
- Run: nothing to install; the pages are plain files. Open https://danielyoonwrites.github.io/video-editor (the app; add `?owner` for the captions passcode) or https://danielyoonwrites.github.io/video-editor/phone-test.html (the phone test), or serve the repository folder (`python3 -m http.server`) and open `/video-editor/`.
- Check the app (needs Playwright with Chromium, and ffmpeg; both are installed in Claude's cloud sessions): `node video-editor/tests/app-test.mjs` from the repository folder. It makes made-up test videos, a color chart, a "clock" video and test sounds with ffmpeg (`tests/test-videos.mjs`), serves the repository on http://127.0.0.1:8768 (that port must be free) and runs Chromium at 360 wide with touch, 180 wide (a phone at 200% zoom) and 1280 with a mouse. Success ends "250 passed, 0 failed" (about 2 to 3 minutes); screenshots go to the temporary folder it prints.
- Check the captions server (after any change to `server/`): `node video-editor/tests/server-test.mjs` (a stand-in AI, a made-up passcode; a few seconds). Success ends "84 passed, 0 failed"; it also prints how long the biggest piece takes on this computer. To check `wrangler.jsonc` without deploying: copy `server/` to the scratchpad and run `npx --yes wrangler@latest deploy --dry-run --outdir out` there (`CLOUD-NOTES.md`); it should list `env.AI`.
- After Dan's setup, each merge should show Cloudflare's check next to it (likely "Workers Builds: video-editor-captions"), through https://api.github.com/repos/danielyoonwrites/danielyoonwrites.github.io/commits/<commit>/check-runs?filter=all (`CLOUD-NOTES.md`).
- Check the Projects page listing (after changing its line or note): `node video-editor/tests/projects-listing.mjs` (port 8794). Success ends "20 passed, 0 failed."
- See the looks side by side: `node video-editor/tests/looks-sheet.mjs` (port 8769; needs Python with Pillow and numpy). Check the phone test: `node video-editor/tests/phone-test.mjs` (port 8767); success ends "71 passed, 0 failed."
