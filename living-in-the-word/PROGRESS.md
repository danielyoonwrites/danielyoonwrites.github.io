## How to run and check it
- Run: the app is plain files that GitHub Pages publishes after each merge. The server is the Cloudflare Worker `living-in-the-word`, which Cloudflare deploys after each merge, using `server/wrangler.jsonc`. Its secrets are kept in Cloudflare by name: `ANTHROPIC_API_KEY`, `PASSCODE`, `RESEND_API_KEY` and `OWNER_EMAIL` (`ESV_API_KEY` isn't set; the ESV is on hold). On Claude's computer: `python3 -m http.server 8765 --bind 127.0.0.1` from the repository folder, then http://127.0.0.1:8765/living-in-the-word/ (the server answers only the real site and this address).
- Check: from the repository folder, `node living-in-the-word/tests/server-test.mjs && node living-in-the-word/tests/app-test.mjs`. Success (since pull request 122): "93 passed, 0 failed", then "128 passed, 0 failed". The app checks use ports 8765 (the app) and 8766 (a stand-in site for the offline helper's checks), which must be free, and Playwright's Chromium (installed in Claude's cloud sessions). When `app.js` or `style.css` changes, raise its `?v=` in `index.html` and put the new fingerprint the VERSIONS check prints into `KNOWN` in `tests/app-test.mjs`.
- Check the settings file without deploying: copy `server/worker.js` and `server/wrangler.jsonc` to a scratch folder and run `npx --yes wrangler@latest deploy --dry-run --outdir out` there. It should list `env.DB (living-in-the-word-limits)`.
- Check a deploy: Cloudflare's "Workers Builds: living-in-the-word" check next to the merge, through https://api.github.com/repos/danielyoonwrites/danielyoonwrites.github.io/commits/<commit>/check-runs?filter=all. Its log is only in Dan's Cloudflare account. If a build fails, paste by hand meanwhile (https://dash.cloudflare.com, Compute, Workers & Pages, `living-in-the-word`, Edit code). If a deploy breaks the server, revert the pull request on GitHub (its "Revert" button) and merge the revert.
- On a phone: https://danielyoonwrites.github.io/living-in-the-word/?test shows, in "Prepare for a Bible study," which AI wrote a set, its tokens and cost, and how long the wait was (the AI's part too). Updates reach the installed app within about 10 minutes; then close and reopen it.
