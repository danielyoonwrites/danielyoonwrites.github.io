# First step smaller

Read `PROGRESS.md` first (where it stands and the next step), then `DECISIONS.md` (choices and their reasons) and `SPEC.md`.

A little app for facing something you've been putting off, one small step at a time. It lives in this folder and is published at https://danielyoonwrites.github.io/first-step-smaller. Keep the "Build plan" in `SPEC.md` up to date.

## Rules for working here

- Same rules as the website's `CLAUDE.md`: plain words for a beginner, one small change per pull request with a check the owner does, no build tools, Moon jar design (in `.claude/rules/moon-jar.md`, which Claude Code loads by itself when working in this folder), phone first.
- It's a little app, not a therapy tool. Never claim it treats or fixes anything.
- Kind words only: no streaks, no guilt, no red marks. Stopping is always fine.
- One thing per screen, with big buttons and short sentences.
- Never send what people type anywhere. Save it only in the browser (`localStorage`, key `first-step-smaller`). No accounts, analytics or tracking.
- Keep the saved data and the backup file the same versioned JSON, so old backups keep working.
- Raise the `?v=` number on file links whenever a file changes.
